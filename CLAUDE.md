## What this is

A falling-sand cellular automaton with an alchemy discovery meta-layer (40 reactions, codex, 11 trial scenarios). Arrived as two single-file HTML downloads; rebuilt as a proper web app with a diegetic laboratory presentation. 2D now; a 3D variant (sim inside glassware on a 3D bench) is a plausible future fork.

## Layout

- `src/` — the game: `sim/` (pure core), `render/`, `audio/`, `ui/`, `platform/`
- `docs/` — design + ops docs: `PLAN.md` (locked decisions), `SHIPPING.md` (target ladder), `ANALYSIS.md`, `SIM_AUDIT.md`, `AUDIO_RESEARCH.md`, `STACK_RESEARCH.md`
- `reference/` — the two prototype HTML files; v2 is canonical (its trial persistence used `window.storage`, a claude.ai artifact API — silently no-ops locally)
- `src-tauri/` — Tauri 2 desktop shell; `android/` — Capacitor 8 project
- `.github/workflows/deploy.yml` — test-gated Pages deploy on every push to main
- `demos.html` + `src/demos/` — dev-only showcase-video pipeline: 13 scripted scenes + an end card running the real sim core live (open `/demos.html` under `npm run dev`; not part of the production build, which only builds `index.html`). Each scene is its own pure DOM-free module under `scenes/`; `scenes.ts` assembles `SCENES[]` + `END_CARD`; `lib.ts` holds the `Scene`/`Cap` contract + paint helpers + colorizer. `record.ts` is a headless Node recorder that renders to **4K** (180x120 sim → 18x nearest upscale → 3840x2160), bloom + vignette + Palatino-ink ASS captions + per-scene fades, concats `showcase-silent.mp4`, and emits `timeline.json` (scene boundaries + caption/discovery-event times). `proto.ts` is a single-scene frame harness (PNG + event report) for verifying a scene on the exact frames the recorder will produce (`--seed`). Build: `npx esbuild src/demos/record.ts --bundle --platform=node --format=cjs --outfile=video-out/record.cjs && node video-out/record.cjs`. `record.ts` + `proto.ts` are excluded from tsconfig (Node-side).
- `score/` — dev-only music pipeline (uv/Python): one through-composed felt-piano piece (A minor / C major) driven by `timeline.json`, written in the C418 grammar (Sweden/Wet Hands) per Matt's direction 2026-06-12. `compose.py` (the composition: one global 60 BPM pulse with every scene's bar-zero an integer second at its cut, constant arpeggio left hand with the root exactly on each downbeat, ONE fixed diatonic theme - an 8-bar period, antecedent Am-Dm-G-C ending on the relative major, consequent F-G-Am answering home - stated, developed, recapped octave-up in C major over the reef, apotheosized over the Opus with a major ending; no RNG picks pitches or rhythms; accents quantized to whole beats on corrode/ignite/detonate+vitrify/crystal/immis/calcine/coagulate), `check_grid.py` (structural audit: grid adherence + chord-tone discipline), `render.py` (FluidSynth + Salamander piano → felt chain kept bright enough that attacks stay articulate → synthetic IR reverb, RT60 ~3.8s lows), `analyze.py` (LUFS + spectrogram), `finalize.py` (two-pass loudnorm -14 LUFS / -1 dBTP + mux), `make_publish.py` (thumbnails + `docs/UPLOAD_COPY.md`). ## Rules for this subtree

- The simulation core stays pure and framework-free (no DOM/audio imports in `src/sim/`) so it remains testable and portable to the 3D variant.
- Presentation doctrine: diegetic over chrome. No glass panels, no floating docks, no backdrop-blur. Ink, parchment, brass, chalk. Desktop and mobile are both first-class: cabinet on wide screens, thumb strip on narrow.
- Sandbox is never gated; trials only teach.
- Keep `package.json`, `src-tauri/tauri.conf.json`, and Android versionName in step when releasing; tag `vX.Y.Z` + `gh release create` with artifacts.
- Lab sequencing rules in `lab/CLAUDE.md` apply; this is a deliberate exception to "no new repos before inventory" per Matt's direction 2026-06-11 (first lab game).
